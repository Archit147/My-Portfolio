# Project Video Prompts

Use these as 5-second seamless-loop prompts for the portfolio project cards. Export each as a silent H.264 MP4 at 960x640, 30 fps. Use a locked camera, no readable UI text, no watermarks, and motion that returns exactly to the opening frame.

## PhishGuard - `storekit.mp4`
A premium browser-security identity animation for PhishGuard: a glowing crimson shield scans a dark browser-like grid, detects a hostile red signal, and seals it outside the shield with a clean pulse of light. Trustworthy, privacy-first, minimal, no readable text or UI screenshot, seamless loop.

## Suscode - `codingducks.mp4`
A tense multiplayer coding-game animation for Suscode: several cyan code nodes work together to complete a glowing task, while one hidden red node quietly disrupts the connection. The red node disappears back into the network as the crew formation returns to its opening state. Inspired by social deduction games, technical and cinematic, no readable code, seamless loop.

## Spot It - `gumbalup.mp4`
A polished parking-reservation animation for Spot It: a lime-green location pin moves across a dark map-like grid, finds an open parking space, and locks it with a bright circular confirmation pulse. The map gently returns to its starting position. Clear, fast, useful, no readable labels or UI screenshot, seamless loop.

## FaceFlirt AI - `waku.mp4`
A futuristic AI-companion animation for FaceFlirt AI: a violet human-like profile made from soft particles responds to a warm glowing speech pulse, then transitions into two connected video-call frames before returning to the single companion silhouette. Modern, intimate, safe, no realistic person, no readable text, seamless loop.

## MindEase - `peakposts.mp4`
A calm mental-health support animation for MindEase: an amber breathing ring slowly expands and contracts around a soft neural light, while small anxious fragments settle into a balanced pattern. Gentle, reassuring, student-friendly, never clinical or dark, no text, seamless loop.

## Salvage Crew - `kanbi.mp4`
An underwater survival-game animation for Salvage Crew: a blue submarine lamp sweeps across a dark ocean wreck, reveals a valuable salvage crate, and sends a pulsing route back toward the crew. Suspenseful ocean atmosphere, inspired by cooperative extraction games, no readable UI, seamless loop.

## My Portfolio - `portfolio.mp4`
A distinctive developer-portfolio animation: a glowing pink orbital ring rotates around a glassy geometric core while tiny stars and code-like particles drift in depth. The ring completes one elegant cycle and returns to its exact opening angle. Premium, playful, futuristic, no readable text or UI screenshot, seamless loop.

## Negative prompt
Hard cuts, camera shake, rapid flashing, excessive particles, fake typography, watermarks, unrelated logos, browser chrome, UI screenshots, hands, audio, gore, and motion that does not return to the first frame.
